## درباره پروژه

پروژه **V2Ray Config Modifier** یک اپلیکیشن تحت وب (HTML و JavaScript) است که به کاربران اجازه می‌دهد به سرعت و به صورت دسته‌جمعی، کانفیگ‌های مختلف (مانند VMESS، VLESS، Trojan، Shadowsocks و...) را برای رنج‌های مختلف IP یا لیست‌های سفارشی تولید و بهینه‌سازی کنند.

## امکانات و ویژگی‌ها

- 🌙 **حالت تاریک (Dark Mode):** امکان سوئیچ بین تم روشن و تاریک با ذخیره خودکار تنظیمات.
- 🔍 **بررسی‌کننده کانفیگ (Config Inspector):** آنالیز و نمایش جزئیات پارامترهای کانفیگ پایه (آدرس، پورت، UUID، نام و...).
- 🔄 **حذف خودکار موارد تکراری (Deduplication):** فیلتر و حذف هوشمند IPها و کانفیگ‌های تکراری در خروجی.
- 📦 **فرمت‌های خروجی متنوع:** پشتیبانی از خروجی متن ساده (Plain Text)، کلش (Clash YAML) و سینگ‌باکس (Sing-box JSON).
- 🔗 **لینک سابسکرایب Base64:** تولید و کپی سریع لینک اشتراک (Subscription Link) از تمام کانفیگ‌های تولید شده.
- 📱 **تولید QR Code:** قابلیت اسکن سریع QR کد برای تک‌تک کانفیگ‌ها و لینک سابسکرایب.
- 🔀 **تنظیمات پیشرفته:** امکان تعیین پورت سفارشی (Port Override) و شافل تصادفی ترتیب خروجی‌ها.
- 💾 **ذخیره خودکار (LocalStorage):** حفظ اطلاعات و تنظیمات وارد شده در مرورگر بین جلسات.

## پروتکل‌های پشتیبانی‌شده

- **VMESS**
- **VLESS**
- **WireGuard**
- **Trojan**
- **Shadowsocks (`ss://`)**
- **Hysteria (v1 / v2 / `hy2`)**
- **TUIC**

## راهنمای استفاده

### گام ۱: وارد کردن کانفیگ پایه
- کانفیگ پایه خود را در کادر مربوطه وارد کنید.
- می‌توانید با کلیک روی دکمه **Inspect Config** جزئیات آن را مشاهده کنید.

### گام ۲: انتخاب روش ورودی
- **محدوده IP (CIDR):** ورود رنج IP یا استفاده از رنج‌های آماده CDNهای معتبر (Cloudflare، Gcore، Fastly).
- **لیست IP:** وارد کردن لیست دستی IPها.
- **لیست کانفیگ‌ها:** وارد کردن لیستی از کانفیگ‌ها جهت استخراج IPها.
- **SNI Spoof:** تنظیم IP و پورت Spoof.

### گام ۳: تولید و خروجی
- روی دکمه **Generate Configs** کلیک کنید.
- فرمت خروجی دلخواه (Plain Text، Clash یا Sing-box) را انتخاب کنید.
- کانفیگ‌ها را کپی کنید یا فایل خروجی را دانلود نمایید.
